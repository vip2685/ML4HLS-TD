# ML4HLS-TD

The extracted and summarized dataset of non-infected (NoI) and Trojan infected (TI) features along with labels for different IP designs have been made publicly available by us here in GitHub [1]. The description of different IP designs or benchmarks along with their transfer functions, control data flow graphs (CDFGs) are also available here. These HLS benchmarks are taken from [2], [3]-[5]. This dataset consists of total 30 unique features (NoI and TI), whose names are defined in the first row. Another 170 rows contain the instances of different NoI and TI IP designs. In the database, NoI instances are labeled as ‘0’, and following Trojan infected instances are labeled as '1': PD-HT, DoS-HT, BE-HT, DA-HT, F-HT, TB-HT, TST-HT, T-HAC, and RAT-HT. The main motive of the proposed ML based detection approach is to present binary classification (i.e., non-infected or Trojan infected). Non-infected and Trojan infected IP designs are distributed across 18 instances and 152 instances respectively.
